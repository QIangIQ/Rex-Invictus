**[[Incantation Sound Tables]]** list the sound for each attribute value used by [[Spell Speech (Incantation)]]. Source sounds come from *The Spell Saying Guide*. Sounds marked Rex Invictus were assigned by the registry for values the guide never needed, using unused syllables so that no two features share a sound.
