**[[Spell Writing (Glyph Notation)]]** is the written form of a working: a polygon of points with one layer of chords per attribute. It follows the Unique Binary Scheme of *How to Write Spells* (The Gorilla of Destiny, 2022) and its two dictionaries ([[Source Texts (Theoretical Magic Corpus)]]), extended in Rex Invictus to six attributes on 13 points. Every note in the [[Spell Registry]] carries its glyph.

## Principle

Points are placed as the vertices of a regular polygon. An attribute is drawn as a set of chords that all skip the same number of vertices, k: Tier uses k = 1 (edges), School k = 2, Damage k = 3, Area k = 4, Range k = 5, Duration k = 6. Each feature is a binary string of length n; a 1 at a vertex draws the chord from that vertex to the vertex k steps along.

**Single-Line Scheme (rejected).** The first idea in the source gives each feature one chord. It fails because a rotated scroll reads as a different working: a chord from 1 to 2 looks like 3 to 4 if the page is turned.

**Unique Binary Scheme (used).** Each feature takes a binary string that stays distinct under every rotation (a cyclically unique number, a necklace). The glyph then reads the same however the page is turned.

## Building the key list

1. Count the attributes N and choose **n ≥ 2N + 1** points. Chords with k above n/2 repeat shapes of smaller k, so each attribute needs its own k up to n/2.
2. Generate all n-bit strings and drop the all-zero and all-one strings.
3. Group the rest by rotation and keep the smallest of each group.
4. Sort ascending and hand them out in order: the first feature gets 0…001, the second 0…011, the third 0…101, then 0…111, 0…1001.

The number of unique codes for prime n is **N_uniques = (2ⁿ − 2)/n + 2**: 188 for n = 11 and 632 for n = 13.

| Edition | Attributes | n | Codes per attribute |
|---|---|---|---|
| 2022 guide and 2023 dictionary | Level, School, Damage, Area, Range | 11 | 188 |
| Rex Invictus | adds Duration | 13 | 632 |

## Reading and drawing convention

Recovered from the 2022 Symbolic Dictionary plates (pages 14 to 17), where every code is drawn on an 11-gon:

- The **rightmost bit** belongs to the **top-right vertex**. Moving left through the string moves **counter-clockwise** round the polygon (top-right, top-left, upper-left and so on).
- A 1 draws a chord from that vertex to the vertex **k steps clockwise**.
- The plates draw all possible chords as faint dotted lines and the "on" chords solid. The 2023 runes add a filled marker on the vertex one step clockwise from the top-right; it is an orientation mark, not part of the code.

Registry glyphs follow the same convention on 13 points, with each layer in its own colour (k1 pale gold, k2 violet, k3 red, k4 cyan, k5 green, k6 amber).

## Feature order

Source features keep the source order, which is ASCII order of the label for Level, School, Damage and Range. The 2022 Area list is an exception: its codes follow an unstated source order and are only displayed alphabetically, so they cannot be regenerated by sorting. The registry uses the 2024 area vocabulary, shape plus size, which it orders by ASCII, and appends every Rex Invictus addition after the source list so that no source code ever moves. The full lists are in [[Glyph Key Tables]].

## Line styles

The scheme does not fix how a chord is drawn, only which vertices it joins. The source gives four families of style:

| Style | Description |
|---|---|
| Straight chords | The default; used in all dictionary plates and the registry. |
| Centred circles | Each chord becomes an arc of the circle centred on the polygon's centre, clipped to the polygon. Shown on Eldritch Blast. |
| Non-centred circles | Each chord becomes an arc of a circle through both vertices with its centre pushed out by a factor b. Small b loops outside the polygon; b near 100 is almost straight. |
| Non-polygon bases | The points sit on a semicircle (Acid Splash), a cubic curve (Fire Bolt), a narrow quadratic (Ice Storm, Scorching Ray) or a quarter circle (Lightning Bolt, Blight). |

Styles are a caster's handwriting. They do not change the code, but they change the somatic kata ([[Somatic Notation (Gesture)]]) and so the field's reading of the pattern; practitioners of the same [[Esoteric Traditions|tradition]] share a style.

## Duplicate glyphs

Six attributes still leave groups of workings with identical codes. The 2024 dictionary advises adding dots in the centre of the polygon to tell repeats apart. The registry places one dot for the second member of a group, two for the third, and so on, ordered by source then name. There are 21 such groups, for example Bane, Bless and Hideous Laughter, and Barkskin, Enhance Ability, Magic Weapon and Spider Climb.

The hand-lettered example page of the 2022 guide draws each attribute separately and then overlays them. On 13 points the registry version is:

## Lore consequences

The source suggests three uses that Rex Invictus adopts:

- **Cluster workings.** Glyphs that share an edge can be tiled, the shared side on or off in both. Tiled workings can be cast together or stored compactly. In Rex Invictus a cluster is the written form of a combination, and edge-sharing members have lower link friction ([[Recast Tension and Combination Affinity]]).
- **Stellar workings.** Constellations are point sets, so a working can be written on the sky. Seasonal and lunar casters learn workings that only exist when their stars are up. See [[Arcane Spectroscopy]] for the astronomical side.
- **Enchantment marks.** Smiths and enchanters write a partial glyph (Fire, plus the tier) on an object as a reminder or a warning. Field troops read such marks on captured gear before touching it.
