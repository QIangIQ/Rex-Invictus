# TFBW Name Conversion Bank

Up: [[To Fly on Borrowed Wings]]. Rules: [[TFBW Section Rules and Decisions]].

Conversion bank for patching the draft manuscript later. Each row maps the draft tag and the draft (disliked) name to the new name and the token-level swaps used for aliases and ranks. Real historical people keep their real names and are not listed. Gabriel, Therese, Leona and Eugenia were kept at the author's request.

Naming rule used: new names match the nationality, era and form of the old one (surname only stays surname only, first name only stays first name only, "von" and rank prefixes kept, spelling-variant pairs kept as pairs), read as plausible 1910s names, and avoid exact matches to real 1910s leaders, the UOE name banks and existing vault note names. Where a surname ties a character to a real family or to a kept character (von Seeckt, Cavendish, Mavrocordatos) only the given name changed.

## Manuscript patch notes

- Old protagonist name in the draft text: Friedrich Morin / Friedrich von Morin → Gabriel Jagdfeld / Gabriel von Jagdfeld. Therese was Cecilia, Eugenia was Patricia, Leona was Leonia in the original book text.
- Old pet name "Fritz" (Therese for the protagonist) is removed for now (author, 2026-11-26).
- Generic first names (Hans, Karl, Otto, Fritz) also belong to real people in the story, so patch by context, never by blind find-and-replace.
- "Spell Jaeger" is a Britannian unit type and stays; only the master sergeant named Jaeger became Förster.
